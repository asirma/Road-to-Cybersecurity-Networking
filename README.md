# Road-to-Cybersecurity-Networking

Presentación:
Este repositorio recoge mi evolución y aprendizaje en el ámbito de las redes y la ciberseguridad. Aquí documento laboratorios, prácticas, análisis de eventos, investigaciones y diferentes ejercicios realizados durante mi formación.
El objetivo no es únicamente guardar los ejercicios realizados, sino mostrar cómo ha evolucionado mi forma de analizar problemas, utilizar herramientas y documentar resultados.

Objetivo del repositorio:
El objetivo principal es construir un portfolio técnico que permita recopilar y demostrar los conocimientos adquiridos en:
Fundamentos de redes.
Configuración y simulación de redes.
Análisis de tráfico.
Monitorización y análisis de eventos.
Fundamentos de un SOC.
SIEM y monitorización de seguridad.
Investigación y análisis de incidentes.
Cada laboratorio incluye, cuando corresponde, una explicación del objetivo, configuración realizada, pruebas, evidencias, problemas encontrados y conclusiones.

Índice de laboratorios

Fundamentos de redes:
Conceptos básicos relacionados con redes, modelos OSI y TCP/IP, direccionamiento IP, protocolos y funcionamiento de las comunicaciones.

Packet Tracer:
Laboratorios prácticos realizados mediante Cisco Packet Tracer.
Incluye prácticas relacionadas con:
VLAN.
Comunicación entre dispositivos.
Inter-VLAN Routing.
DHCP.
DNS.
Configuración de switches y routers.

Wireshark:
Análisis de tráfico de red mediante capturas de paquetes.
Se documentarán diferentes protocolos, comunicaciones y evidencias obtenidas durante el análisis.

Windows Events:
Análisis de eventos de Windows mediante Event Viewer.
Se incluyen ejercicios relacionados con:
Inicios de sesión.
Intentos de acceso.
Creación de usuarios.
Cambios de privilegios.
Instalación de servicios.
Correlación de eventos.

SOC Fundamentals:
Fundamentos del funcionamiento de un Security Operations Center.
Se documentan conceptos relacionados con:
Analistas SOC N1 y N2.
Monitorización.
Alertas.
Logs.
Detección de incidentes.
Escalado de incidentes.
Flujo de investigación.

Wazuh:
Laboratorios relacionados con monitorización y detección mediante Wazuh.
Se incluyen ejercicios sobre:
Agents.
Alerts.
Severity.
Authentication events.
Inventario.
Análisis de logs.
Utilización de Wazuh en un entorno SOC.

Casos de investigación:
Casos prácticos orientados a la investigación y análisis de posibles incidentes de seguridad.
Cada caso busca seguir un proceso similar al utilizado en un entorno real:
Identificación del incidente.
Recopilación de evidencias.
Análisis y correlación de eventos.
Formulación de hipótesis.
Investigación adicional.
Medidas de contención.
Conclusiones.

Próximos objetivos de aprendizaje:
Mis próximos objetivos están orientados a seguir profundizando en ciberseguridad y administración de sistemas:
Mejorar el análisis de tráfico de red con Wireshark.
Profundizar en TCP/IP y protocolos de red.
Aprender técnicas de detección y respuesta ante incidentes.
Ampliar los conocimientos sobre herramientas SIEM.
Profundizar en Wazuh y otras herramientas de monitorización.
Practicar análisis de logs y correlación de eventos.
Introducir herramientas como Nmap, Snort y OpenVAS.
Continuar desarrollando laboratorios prácticos de ciberseguridad.
Mejorar la documentación técnica de cada investigación.

Evolución
Este repositorio irá creciendo junto con mi formación. La intención es que cada nuevo laboratorio no solo añada una herramienta o tecnología, sino que también refleje una mejora en mi capacidad para analizar, investigar, resolver problemas y documentar técnicamente los resultados.
